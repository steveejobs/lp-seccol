# Instruções permanentes do projeto

Antes de alterar este projeto, leia integralmente `PROJECT.md` e `reference/README.md`.

Regras obrigatórias:

1. Atualize `PROJECT.md` quando houver decisão, mudança estrutural, nova dependência, ferramenta, risco ou etapa concluída.
2. Trate `reference/site-original/` como imutável. Nunca use o site antigo como base visual ou de código.
3. Não invente informações comerciais. Consulte `reference/catalog/knowledge-base.json` e confirme em `pages.json`.
4. Mantenha tema, motion e componentes centralizados nas pastas definidas em `PROJECT.md`.
5. Preserve acessibilidade, responsividade, performance e `prefers-reduced-motion` em toda implementação.
6. Não implemente a hero definitiva antes da aprovação explícita da direção de arte.
7. Execute `npm run check` antes de concluir alterações de frontend.
